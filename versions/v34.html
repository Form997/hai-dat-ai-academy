Hướng tích hợp API thật

Frontend → backend có xác thực → giới hạn độ dài / số lần / chi phí → API nhà cung cấp → lưu trạng thái và trả kết quả. Khóa API chỉ ở backend. Không cho trình duyệt truyền tùy ý địa chỉ provider. Chưa cung cấp endpoint giả làm dịch vụ sinh ảnh.
