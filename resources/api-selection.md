# Chọn API ảnh, nhạc, video

| Tiêu chí | Câu hỏi cần kiểm chứng |
| --- | --- |
| Tài liệu chính thức | Có endpoint và ví dụ còn hiệu lực? |
| Chi phí | Có mức miễn phí thật không, quota và hạn dùng thế nào? |
| Giấy phép | Cho phép dùng thương mại và chia sẻ đầu ra không? |
| Bảo mật | Backend giữ key, có cơ chế rotate và quota? |
| Tạo nhạc | Có tạo bài hát hay chỉ text-to-speech? |
| Tạo video | Hỗ trợ đồng bộ hay job bất đồng bộ? |

Không công bố API là miễn phí vô hạn nếu chưa có cam kết chính thức. Dự án hiện chưa tích hợp provider thật.
