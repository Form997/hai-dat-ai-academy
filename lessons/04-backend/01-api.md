# API và luồng request

## Mục tiêu
Trình duyệt gửi request tới backend; backend kiểm tra input/quota và gọi provider, giữ khóa phía máy chủ.

## Kiến thức cần nhớ
Trình duyệt gửi request tới backend; backend kiểm tra input/quota và gọi provider, giữ khóa phía máy chủ. Người học nên thao tác trên bản sao hoặc nhánh riêng; kiểm tra kết quả trước khi chia sẻ công khai.

## Thực hành
Vẽ sơ đồ Client → Backend → Provider và mô tả lỗi 400, 401, 429, 500.

## Tự đánh giá
Không chèn API key vào index.html; https://owasp.org/API-Security/

## Ghi chú
Bài học là tài liệu nhập môn có thể mở rộng, không thay thế tài liệu kỹ thuật của nhà cung cấp. Hãy dẫn nguồn khi đóng góp thêm.
