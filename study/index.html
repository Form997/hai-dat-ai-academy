12 bài học AI có địa chỉ riêng

Đọc trực tiếp bằng HTML, không phụ thuộc JavaScript để tải nội dung. Đây là học liệu nhập môn, chưa phải chứng nhận đã hoàn thành kiểm định học thuật.

  1. GitHub căn bản: repository, branch, commit và pull request
  2. Bảo mật tài khoản GitHub và API key
  3. HTML, CSS và thiết kế website tương thích điện thoại
  4. JavaScript DOM và triển khai GitHub Pages
  5. Viết prompt tạo ảnh AI và kiểm định kết quả
  6. Prompt âm nhạc AI: nhịp độ, nhạc cụ và cấu trúc
  7. Prompt video AI và storyboard nhất quán nhân vật
  8. API AI: request, response, xác thực và mã lỗi
  9. Triển khai backend AI an toàn và quản lý secrets
  10. Kiến trúc mô hình AI: Transformer, diffusion và inference
  11. Thiết kế hệ thống AI: hàng đợi, retry và giám sát
  12. Nghiên cứu AI tái lập: dữ liệu, seed và sai số
