# Học viện AI V3.0 — Giáo trình theo chương

Bản V3.0 đầu tiên gồm 8 chương mẫu có bài tập và lời giải, phân thành 3 cấp. Đây chưa phải toàn bộ chương trình chuyên sâu. Các trang được xem qua trình đọc của học viện để không thấy ký hiệu Markdown thô.

## Lộ trình

1. Quản lý dự án với Git và GitHub — Cơ bản
2. HTML, CSS, JavaScript và web tĩnh — Cơ bản
3. Python và chất lượng dữ liệu — Cơ bản
4. Học máy và kiểm định mô hình — Trung cấp
5. PyTorch và huấn luyện có tái lập — Trung cấp
6. Transformer, truy xuất tài liệu và RAG — Chuyên sâu
7. Đánh giá AI tạo ảnh, nhạc và video — Chuyên sâu
8. An toàn API, vận hành và quản trị rủi ro — Chuyên sâu

## Quy trình học và kiểm tra

Đọc nguyên lý → làm thực hành → trả lời bài tập → đối chiếu lời giải → ghi bằng chứng kiểm nghiệm và nguồn. Với bài tập mở, lời giải chỉ là một hướng tiếp cận và không thay thế kiểm tra độc lập.

## Nguyên tắc nguồn

Ưu tiên Git/GitHub, MDN, Python, scikit-learn, PyTorch, tài liệu bài báo gốc và NIST/OWASP. Không suy diễn từ bài báo rằng sản phẩm thương mại có API công khai hoặc miễn phí.

## Nâng cấp tiếp

Cần mở rộng mỗi chương thành nhiều tiết, thêm notebook/code chạy tự động, đề thi lớn hơn, tập dữ liệu có bản quyền rõ và hoạt động nhóm.
